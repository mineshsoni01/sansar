# Contributing

Guidelines for contributing to the SANSAR product documentation.

## How to contribute

1. Use the templates in `08-standards/01-templates/` as a starting point for new documents.
2. Follow the naming conventions in `08-standards/02-naming/`.
3. Use terms consistently as defined in `08-standards/03-glossary/`.
4. Follow the writing style in `08-standards/04-writing-guidelines/`.
5. Run through the relevant checklist in `08-standards/05-review-checklists/` before requesting review.
6. Open a pull request for review before merging to `main`.

## Document lifecycle

New discovery, journeys, and PRDs are filed under the current year/quarter (e.g. `04-prd/2026/Q1/`). An `INDEX.md` in each quarter folder tracks the documents created in that period.
